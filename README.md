# EvoSim

Real-time natural selection inside Minecraft. Creatures with heritable traits
(speed, size, vision, colour) forage for food in an arena, pay energy for
their traits, reproduce with mutation, and die. Watch the population adapt.

## Requirements

- Paper 26.2
- JDK 25 (Paper 26.1+ requires Java 25)
- Gradle 9.1+ (`gradle build`, or open in IntelliJ)

## Build

    gradle build

The jar is written to `build/libs/`.
